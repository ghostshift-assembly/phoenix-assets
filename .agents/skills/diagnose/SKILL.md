# Diagnose an asset boundary failure

Capture sanitized declaration/configuration, resolved preset/plugin order,
generated path/hash, runtime/peer versions and original command/error. Follow
one minimal host specimen; do not copy product policy or credentials into fixtures.

Distinguish the seams before changing code:

- Source/resolution: [Config](../../../lib/phoenix_assets/config.ex), plugin
  availability/order and `Engine.init_plugins/1`.
- Generated bytes: [Generated](../../../lib/phoenix_assets/generated.ex),
  deterministic no-write/drift behavior and the owning DSL/generator.
- Browser import: Vite virtual module, warning/stub, watch/HMR and actual on-disk
  contract. A typed stub must not hide missing generation.
- Runtime/backend: shape URL/auth/parser/collection behavior, Phoenix.Sync/Electric
  or optional module availability. Source generation and live backend differ.
- Child/process or DocShell: [DevProcess](../../../lib/phoenix_assets/dev_process.ex)
  lifetime versus host supervision; producer contract versus renderer projection.

Probe a causal hypothesis that predicts different output from alternatives.
Use [generated tests](../../../test/phoenix_assets/generated_test.exs),
[process tests](../../../test/phoenix_assets/dev_process_test.exs),
[HMR tests](../../../npm/vite/test/hmr-bridge.test.ts) or
[shape-auth tests](../../../npm/svelte/test/shape-auth.test.ts) for the owning seam.
Fix source/generator/runtime ownership rather than a generated-file patch,
broad rescue, product-specific option or weaker optional peer requirement.

If evidence rejects the cause, remove only its exploratory edits and preserve
unrelated changes/independently useful diagnostics. Reopen host/config/protocol
assumptions when repeated patches fail. Retain the minimized regression, rerun
the original host path and select adjacent public proof using
[package-proof](../package-proof/SKILL.md).

Report cause and observed results with source/pkg/peer/runtime identity. Missing
Node, watcher, optional producer or backend is unavailable evidence, not a
successful integration or permission to install/start unrelated services.
